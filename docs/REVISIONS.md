# Forge revisions

Short trail for packaged builds Jeff can tell apart.

| Version | Notes |
|---------|--------|
| **1.3.12** | **Plan → Code handoff** — flash Plan replies with implementable JSON (`goal`, `files[]`, `edits[]`). After a PASS plan, lead Edit on coder-next gets those existing paths as named files and `require_diff`: if inspect ends with no `---`/`+++`, one extra no-tools turn asks for a unified diff. Check skip on empty pending stays WARN (correct). Live flash tag unchanged (`qwen3.8-flash-next`). |
| **1.3.11** | **Plan evo-ssh** — flash chat no longer embeds the Plan JSON as a `python3 -c` base64 blob (that one-liner split on Windows/OpenSSH and SyntaxError'd). Payload goes on SSH stdin; remote `-c` stays tiny. Helper board SUMMARY counts WARN lines instead of printing zeros. Unsigned `dist-win` shipped; shortcuts target `dist\win-unpacked\Forge.exe`. |
| **1.3.10** | **Honest Plan banner** — Planning stays up until 5090 flash finishes; Coding/inspect cannot steal the banner or wipe Plan text. SSE `alive` heartbeats keep the current phase (`plan` then `coding`) and no longer look like a Plan→Code transition. Plan tokens stay in a `.plan-block` above inspect. Session log records helper ids. Packaged desk stays 1.3.9 until the next unsigned `dist-win` (never kill a live desk to pack). |
| **1.3.9** | **Edit inspect SSE** — thinking banner stays up for the full read/list/grep loop until the first unified-diff token. Desk streams **Inspect round N of 7 — reading …** (not a blank box); round progress is not stripped on quiet intervals. Client idle + server `alive` heartbeats show **qwen3-coder-next:latest · still working** during long coder-next loads. `dist-win.ps1` skips shortcut refresh when the desk is open (warn only, never Stop-Process Forge). |
| **1.3.8** | **Helper pipeline order** — strict Plan → lead Code/edit → Review/Check. Review never calls Empero on an empty diff (skipped with a clear board). Desk phases: **Planning on 5090 flash…** → **Coding…** → **Review…** via SSE `phase` markers. Post-edit helpers stream as they complete. |
| **1.3.7** | **Plan helper UX** — stream 5090 flash plan tokens over SSE so the desk thinking banner is not blank while first tokens arrive (~16 t/s on tower `:11435`). Shows **Planning on 5090 flash…** with model/route detail. Fail-fast only when no first token within 90s. Reuses EVO-SSH route when Legion cannot reach tower directly (same path as `forge check llm`). **Pending Accept** — coder diffs with changes persist to `%LOCALAPPDATA%\\Forge\\pending-accept.json` so Easy/Advanced Accept survives a desk restart. |
| **1.3.6** | **Plan helper** on tower 5090 flash (`qwen3.8-flash-next` via llama.cpp `:11435`, EVO SSH fallback when Legion cannot reach tower). Ask-only plan before lead **Code** on `qwen3-coder-next:latest` — Easy Plan→Code path when Plan is ticked. **Review** stays sequential Empero after edit. **Check** uses flash after edit only when Plan did not already occupy the 5090 (one GPU, sequential). CUDA `qwen3.8:27b` remains normal Ask — no Ask traffic steal. CLI `--helper plan|review|check`. Desk Helpers: Plan / Review / Check ticks. |
| **1.3.5** | Code default + picker + `forge check llm` → `qwen3-coder-next:latest` on EVO AMD `:11437` (30b stays in live picker when tagged). **Helpers** (first slice): optional sequential **review** on `empero-35b-a3b:q4km` after Edit — Ask-only PASS/FAIL/WARN board on pending diff; no second apply. **check** helper slot for 5090 flash wired but WARN/disabled until tower tag exists. Desk Helpers ticks under Go (Easy + Advanced). CLI: `forge edit … --helper review` / `--helper check`. Sequential on AMD — lead Edit then Empero, never parallel. Compare unchanged. |
| **1.3.4** | Farm check **ray** in Easy dropdown + `forge check all`. **temps** = EVO 5070 Ti + CPU, tower 5090 + 5950X, BC-250 dials; 5090 idle/blocked-for-Vast → WARN not FAIL. **apps**: ARIA UI `Accept: */*`; Blender MCP `:9876` TCP. **llm** expect tags match live `/api/ps` (`qwen3.8:27b-q4_K_M`). Empero stays off CUDA; boards CHECK/RESULT/LINES only. |
| **1.3.3** | Easy mode shows **Ask** (default, `qwen3.8:27b`) vs **Code** (`qwen3-coder:30b`) turn picker — no auto-hide. Canned **Farm check** dropdown runs `GET /api/check?name=` (farm, llm, temps, apps, vpn, all) and prints the CHECK/RESULT/LINES board (no LLM status invention). Grok-builder `checks.py`, recipes, `/api/check`, and farm-check skill ship in the package. |
| **1.3.2** | Easy Edit no longer aborts on qwen3-coder `<parameter>` tool XML: outbound chat history is sanitized before Ollama, native Ollama tools are disabled (Forge markup loop only), parser errors retry without tools, desk shows a friendly message instead of raw XML errors. |
| **1.3.1** | Easy/Ask system prompts: files are first-class (Accept/Apply writes locally); clarify CAN/CANNOT (no shell, no deploy/browser automation); Easy capability answers no longer claim “cannot touch the filesystem.” |
| **1.3.0** | Shortcuts target packaged `dist\win-unpacked\Forge.exe` (fallback: installed Setup, then `launch-forge.ps1`); Desktop uses the real Desktop path (OneDrive when redirected). `dist-win.ps1` refreshes shortcuts after build. Easy: Open control after Accept shells out to the last created/changed file; local-git note; SmartScreen first-run hint. |
| 1.2.0 | Easy vs Advanced desk toggle (default Easy when no workspace). Easy: project-name setup (`git init`, no remote), one chat with Ask/Edit routing, single Accept to apply. Advanced: full Files/Git/Vault/Farm desk. |
| 1.1.1 | Edit inspect loop parses mixed tool-call XML (`<tool>`, `<function>`, `<parameter=…>`, `</function>`, `</tool_call>`); raw tool markup never lands in the transcript. Ask mode strips tool XML and nudges Edit for file work. |
| 1.1.0 | Desk restyle + Cursor-like composer: transcript above input, Enter sends / Shift+Enter newline, bounded conversation history, prominent thinking/inspect status, Go disabled while working, version in header. |
| 1.0.0 | Initial Forge desk — CLI-first local Qwen coding desk, Electron shell, inspect-then-diff Edit, farm-brain QC gate. |

Version lives in `package.json`, `pyproject.toml`, and `src/forge/__init__.py`. Unsigned Windows builds: `.\scripts\dist-win.ps1`.

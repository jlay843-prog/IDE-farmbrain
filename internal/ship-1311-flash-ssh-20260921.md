## Incident

Jeff Plan on packaged 1.3.10:

```

- WARN flash: 5090 flash chat failed via evo-ssh: File "<string>", line 1
    import json,base64,urllib.request,sys; p=json.loads(base64.b64decode("eyJtb2RlbCI6...
```

## Cause

`_iter_flash_sse_ssh` / non-stream `flash_chat` stuffed the full OpenAI JSON (Plan prompt + system + history) as base64 inside `python3 -c '…b64decode("…")…'`. Windows OpenSSH quoting + ~8k cmd limit split the one-liner mid-string → remote Python SyntaxError (unterminated string). stderr was then sliced to 160 chars, so the board looked truncated.

## Fix (source 1.3.11)

- Remote `-c` only execs a short b64 **script**.
- Chat payload is `json.dumps(payload)` on SSH **stdin**.
- Helper `format_board` SUMMARY counts PASS/FAIL/WARN lines when totals are missing (no more `0 warn` next to a WARN line).
